# 潮尺 Tidegauge

手机优先的股票分析网页应用：搜索标的、查看 K 线与均线，并生成短线技术面速读。

## 功能

- 股票搜索（美股 / 港股 / A 股代码）
- K 线走势图（MA20 / MA50）
- 区间切换：日 / 周 / 月 / 季 / 半年 / 年
- 基于均线、RSI、MACD、成交量的技术面摘要
- 本地自选列表

## 开发

```bash
npm install
npm run dev
```

打开 http://localhost:3000 。

## 说明

行情通过服务端代理公开接口获取；失败时自动回退到示例数据。分析结论仅供参考，不构成投资建议。
