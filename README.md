# 潮尺 Tidegauge

手机优先的 **A 股与基金** 分析网页应用：搜索标的、查看 K 线 / 净值与均线，并生成短线技术面速读。

## 功能

- 搜索沪深京 A 股、场内 ETF、场外基金（不支持美股）
- K 线 / 净值走势（MA20 / MA50）
- 区间切换：日 / 周 / 月 / 季 / 半年 / 年
- 基于均线、RSI、MACD、成交量的技术面摘要
- 本地自选列表

## 开发

```bash
npm install
npm run dev
```

打开 http://localhost:3000 。

## 说明

行情来自公开接口；失败时自动回退到示例数据。分析结论仅供参考，不构成投资建议。
